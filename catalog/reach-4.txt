# WHY THIS PASS EXISTS
# The R band (100K-1M) is the deck's binding constraint: 388 cards against the
# 408 a 24th lower wall needs, while every other band already clears it. Neither
# existing route reaches R. Published rankings bottom out near 20M (reach.txt,
# reach-2.txt) and model recall thins below ~1M, where recalled handles turn into
# confabulated ones (reach-3.txt). Both routes rank by SIZE, and nothing ranks by
# size at 100K.
#
# Wikipedia's List of YouTubers ranks by NOTABILITY instead, which is the signal
# we actually want and is uncorrelated with subscriber count — a creator with a
# Wikipedia article and 300K subscribers is exactly the R-band card a player
# recognizes. 947 rows, 906 of them carrying an article link.
#
# THE PART THAT MATTERS MOST: THESE ARE IDs, NOT GUESSED HANDLES.
# Every line below came from Wikidata property P2397 (YouTube channel ID) on the
# creator's own Wikidata item, reached from the enwiki article link. So this pass
# structurally cannot repeat reach-3.txt's failure, where five guessed handles
# resolved to squatters sitting on abandoned famous names and merged silently as
# N-band filler. There is no guessing step here to be wrong.
#
# It is also ~50x cheaper. Handles cost 1 quota unit each; UC ids batch 50 to a
# unit, so this entire roster resolves for about 6 units against reach-3's 68.
#

#   - dropped rows with no Wikidata channel id           (947 -> 587 people)
#   - dropped deceased creators                          (-21)
#   - kept only English-speaking territories             (-150)

#     activism, convictions, abuse, child performers     (-42)
#   - dropped ids already in the candidate DB            (-131)
#   - then read all 336 survivors by hand and cut 53 more,
#     listed at the foot of this file with the reason for each
