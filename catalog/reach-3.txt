# Reach roster, pass 3 — recalled from model training data, not read off a list.
#
# WHY THIS PASS EXISTS
# reach-2.txt established that a published ranking already encodes the recognition
# the code cannot compute. This pass uses the same principle with a different
# source: an LLM's training data is, for this narrow purpose, a compressed index
# of which channels were written about enough to be remembered. That makes it a
# recognition signal of the same kind as a ranking, and it costs zero quota to
# query.
#
# ITS LIMIT, STATED UP FRONT. Recall is reliable for IDENTITY and unreliable for
# NUMBERS — subscriber counts and ranks drift and the model's cutoff is fixed.
# That is the same trade reach-2.txt already accepted and for the same reason:
# build-set.js re-hydrates every statistic, so identity is the only thing a
# roster has to get right. Band comments below are therefore guesses, unenforced.
#
# WHAT IT CANNOT DO, WHICH IS THE CURRENT GAP. Nothing here reaches R
# (100K-1M). Published rankings bottom out around 20M and training data thins out
# below ~1M, where recalled handles turn into confabulated ones. The commons
# shortfall is search's job and this file does not touch it.
#
# SELECTION. Diffed mechanically against all 526 handles in legends.txt,
# reach.txt and reach-2.txt (including the commented failed-resolve block), so
# every line below is new. Same exclusions as reach-2: no news or political
# commentary, no non-English, no India-based, no channels built around child
# performers, no deceased creators, no fame-is-an-abuse-case.
#
# DELIBERATELY NOT ADDED: more record-label and music-artist channels. Recall
# offers plenty of 10M-50M ones (Coldplay, Dua Lipa, The Weeknd, Imagine
# Dragons), and DECISIONS.md records that labels falling from 8 of 22 to 4 of 26
# was progress. Adding them back would buy band depth with the exact card nobody
# is chasing.
#
# NO PINS, per reach.txt's convention — this is depth, not chase cards. Several
# lines below would survive a pin argument (@BeastPhilanthropy, @ZackDFilms,
# @DailyDoseOfInternet); make that call after the resolve reports real bands.
#
