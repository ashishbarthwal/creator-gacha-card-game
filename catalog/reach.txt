# Reach roster — recognizable creators for the SR and SSR bands.
#
# WHY A SECOND ROSTER FILE
# catalog/legends.txt answers "who is a chase card" and aims at 10M+, because
# search structurally cannot reach the top bands. This file answers a different
# question that turned out to matter just as much: who does a player actually
# RECOGNIZE. Those come apart hardest between 1M and 10M, where search produces
# plenty of channels and almost none of them are names anyone knows.
#
# The evidence is the first 1,200-card printing. Every recognizable name in SSR
# came from legends.txt; the bottom half of SR came from keyword search and read
# as filler — study-notes channels, clip farms, and creators whose audience sits
# entirely in one non-anglophone market. Those are now held out in
# catalog/excluded.txt, and this file refills the slots they freed.
#
# THE BAR
#   - Recognizable to an English-speaking player without explanation.
#   - Production value or a distinct personality, not volume. Subscriber count is
#     what rarity DERIVES from, so it cannot also be the test for whether a card
#     is worth pulling.
#   - No news, no political commentary, no person-named channels whose fame is
#     controversy — the original KEYWORD_SEEDS restriction, kept deliberately
#     even though the vocabulary around it widened in WP9.
#
# COST  1 quota unit per handle. This roster is ~1 unit a name and reaches
#       exactly the bands search cannot — search is 100 units a call and lands
#       the filler this file exists to replace.
#
# USE   node tools/add-candidates.js catalog/reach.txt --dry-run
#       node tools/add-candidates.js catalog/reach.txt
#
# NOTE  The India exclude applies here exactly as everywhere else, and pins are
#       NOT set in this file — these are depth, not chase cards. Add a leading !
#       only if a name should outrank its band in the cap.
#
